# 📖 Project Overview

**Velvet Petal Café** is a fictional boutique café website created as part of a first-semester Generative AI course project. The project demonstrates how Generative AI tools can help beginners transform a simple idea into a visually appealing, responsive website using natural-language prompts instead of writing all the code manually.

The website is designed around the concept of a dreamy, elegant, and Parisian-inspired café that offers a warm and welcoming digital experience. Its visual identity combines soft colours, elegant typography, premium café imagery, and a clean layout to create the feeling of a sophisticated boutique coffee shop.

The main goal of this project is to explore the practical use of Generative AI in website design and development, particularly how detailed prompts, AI-assisted generation, and iterative improvements can be used to create a complete website.

# 🎯 Project Objectives

- Explore the use of Generative AI in website creation.
- Learn how to convert a written idea into a detailed website-generation prompt.
- Use AI-powered development tools to generate a website with minimal manual coding.
- Understand the importance of UI/UX design, colour selection, typography, and responsive layouts.
- Improve the generated website through clear instructions and follow-up prompts.
- Demonstrate how AI tools can support students and beginners in building digital projects.

# 🎨 Design Concept and Visual Identity

The design of Velvet Petal Café follows a warm, elegant, and feminine aesthetic inspired by small Parisian cafés and premium bakery brands.

- **Warm Cream (`#F7F0E7`):** Creates a soft, welcoming background.

- A respo

The final functionality of each section depends on the generated implementation. Any sample prices, addresses, and contact details are fictional and should be replaced before real-world use.

# 🛠️ How the Project Was Created

The project followed a prompt-based website creation workflow:

1. **Idea Selection:** Selected a fictional boutique café as the website concept.
2. **Requirement Planning:** Identified the target aesthetic, website sections, colour palette, and desired features.
3. **Prompt Engineering:** Prepared a detailed prompt describing the café brand, layout, typography, imagery, and responsiveness requirements.
4. **AI Website Generation:** Submitted the prompt to Bolt.new to generate the website project.
5. **Preview and Review:** Examined the generated design and evaluated its visual presentation.
6. **Iterative Improvement:** Used additional prompts to request specific design and layout refinements.
7. **Testing:** Reviewed the website preview for readability, layout consistency, navigation, and responsive behaviour.

This workflow demonstrates how prompt engineering can guide an AI tool toward a more specific result than a short, generic instruction.

# 📱 Responsive Design

The website is intended to provide a consistent experience across different screen sizes, including desktop computers, tablets, and mobile devices. Responsive design is important because visitors may browse a café website from different devices.

The layout should be checked at multiple screen widths to ensure that text remains readable, images display correctly, and navigation and buttons remain usable.
